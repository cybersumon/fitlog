#B14-A6-Fit Log

Fitlog is a responsive workout library and daily traning planner.Browse exercises, view instructions ,build a plan of up to five workouts,and save exercises for later.

## Technologies

-Next.js 16 (App Router)
-React
-TypeScript
-Tailwind CSS
-React Context
-Browser localStorage

## Features

1. Browse 12 workouts with images, muscle groups ,equipment, duration, calories, and ratings.
2. Open a workout details page with key specs and steap-by-steap instructions.
3. Add up to five workouts to Today's Plan.
4. Save workouts for later and see live Plan and Saved Counters.
5. View Live exercises, mimuts, and calories, total.
6. Mark planned workouts as done or remove planned and saved workouts.
7. Sort workouts by duration , calories or rating.
8. Keep plan and saved items after a page reload with localStorage.
9. Responsive layouts,loading states, notifications, and a 404 page.
